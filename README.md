# Transport Cost Comparator

## Project Overview

The Transport Cost Comparator is an Android application developed to help users analyse and compare transportation expenses.

The application allows users to capture travel information, calculate monthly transport costs, categorise spending, and generate recommendations to help reduce transport expenses.

The project was developed using Android Studio and demonstrates mobile application development, object-oriented programming, database integration, and user interface design.

## Setup Instructions

### Prerequisites

- Android Studio
- Android SDK

### Clone Repository

```bash
git clone https://github.com/P-a-a-r-t-h-M/transport-cost-comparator.git
```

### Open Project

Open the project using Android Studio and allow Gradle to sync.

### Run Application

Connect an Android device or emulator and run:

```text
Run > Run App
```
